# Worst Fix Ever: Funniest Commit Message

Entry for the [Worst Fix Ever: Funniest Commit Message](https://make.fun/c/u-deysumbrella-worst-fix-ever-funniest-commit-message-3f1d9722) competition on make.fun.

`main.ts` writes one commit message — at most 100 characters — for a bug fix that made everything worse, to `/output/entry.txt`:

> fix: resolved the 500 error by returning 404 for everything

The fix "resolved" the 500 error by returning 404 for everything: the error is gone only because nothing can be found anymore.

Run it with Node 22+:

```sh
node main.ts
```

Deterministic: the same fixed line on every run. No randomness, no network, no clock.
